# ДЗ 5. Сохраненная карточка

Домашняя работа по семинару **1-5 «Формы и хранилища: принимаем и сохраняем данные»**.

Нужно самостоятельно собрать небольшое приложение с тремя состояниями:

```text
данных нет → редактирование → просмотр сохраненной карточки
                    ↑                    ↓
                    └──── редактировать ─┘
```

Карточка должна сохраняться между перезагрузками, возвращаться в форму для редактирования и удаляться без восстановления старых данных.

## С чего начать

1. Прочитайте [полное описание домашней работы](docs/HOME_WORK.md).
2. Сделайте fork репозитория и создайте ветку `homework-5`.
3. Откройте [стартовый проект](project/index.html) через Live Server.
4. Выберите тему и самостоятельно спроектируйте поля формы.
5. Реализуйте основной сценарий, затем выбирайте дополнительные возможности.

## Структура

```text
.
├── docs/
│   └── HOME_WORK.md
├── project/
│   ├── index.html
│   ├── styles.css
│   └── script.js
├── AGENTS.md
├── CLAUDE.md
└── README.md
```

В стартовом проекте есть только визуальный каркас. Готовой модели данных, обработчика формы, ключа хранилища и функций сохранения или восстановления нет.

## Результат

К моменту сдачи должны быть доступны:

- замерженный pull request в `master` собственного fork;
- актуальная страница на GitHub Pages по адресу с `/project/`;
- приложение, которое проходит обязательные сценарии проверки;
- код, который вы можете объяснить и изменить по небольшому новому условию.
